## 一句话定位

> **尺素**是一款克制、温柔的私密日记 App。用户写日记，把日记寄给一位虚构的笔友，过几天收到一封回信。

不是社交、不是工具、不是心理咨询。是一个**安静的角落**，让用户跟自己（和一个虚构的笔友）对话。
「尺素」是古人写信用的一尺来长的白绢，后来代指书信。

## 核心功能

### 1. 写日记
- 全屏一张「纸」：日期（自动、不可改）、此时此地（天气 + 地点）、标题（可空，≤40 字）、正文
- 正文是**一整篇连续编辑的图文**：文字可加粗 / 斜体 / 小标题 / 荧光笔；照片浮在段落左右、文字绕排；录音插在段落之间
- 照片装在**相纸**里（原图、宝丽来、和风贴纸、极简卡片、胶片帧、信纸附照），带一点固定的倾斜；可用**尺素相机**拍（存一份进相册）
- **心情**：12 个预设（平静、充实、沉思、喜悦、低落、焦虑、感恩、期待、疲惫、安宁、怀念、希望），**只能选、不能自建**
- **收进日记本**：单选，可当场新建；不选 = 只在「全部日记」
- **点 ✓ 才算写完一篇**；中途退出可存草稿（全局一份），下次接着写
- **墨迹会干**：写下 24 小时后，删字变成划掉、新写的是补记，取下照片留痕迹 —— 过去的日记不能被悄悄改写

### 2. 记录页
- 问候语 + 本月记录天数 + 每日语录
- **列表**（按月分组，用来找）/ **大屏**（一屏一篇左右滑，照片大图，用来重看）

### 3. 日记本（书架）
- 一层层书架板，第一本固定是「全部日记」；日记本数量不限；**长按拿起一本，换个位置放回去**
- 封面：用户自己的照片（满版 / 白框 / 贴照片三种版式）或纯色亚麻布面（8 色）
- 一篇日记最多属于一本；点开一本是**日记本主页**：封面大图 + 目录（从早到晚编号）+「开始阅读」

### 4. 翻页阅读
- 以书的形式从早到晚翻看，一篇读完自动接下一篇
- 每篇首页有页眉（月份、大号日期、心情印章、星期、标题），纸张颜色跟主题

### 5. 邮筒与信箱 ⭐（产品的核心情感）
- **邮筒是寄信的**：上次寄信之后新写的日记列成一叠，勾选后**点邮筒投信**（信封、火漆、投信口、邮戳）
- **信箱是收信的**：笔友的回信在**寄出后 6 小时 ~ 3 天**的随机时刻才到，到了弹通知
- 笔友名用户自己起（默认「青鸟」）；回信用日记写的语言
- 免费：每周一封；会员：写一篇回一篇，信装在**火漆封口的信封**里，第一次打开要拆
- 信件永久保留

### 6. 设置
- 账户（昵称、手机号、注销）、尺素会员、外观（主题、应用图标、启动动画、列表 / 大屏）、日记（默认相纸）、笔友（笔友名）、位置与天气、语言（七种）、数据与备份（同步状态、导出 / 导入备份包、清理残留文件）、写作统计、给我们评分、关于（协议、备案号）

### 7. 主题（三套，全部免费）
| id | 名称 | 外观 |
|---|---|---|
| `bamboo` | 素笺 | 米色纸 |
| `leather` | 皮革 | 深色 |
| `kent` | 肯特 | 黑白 |

每套配一张邮筒插画、一张启动封面、一张桌面图标。选主题时先看一段这种纸的来历。

### 8. 登录
- 手机号 + 验证码（**手机号是账号的必需项**）
- 华为账号：等后端接口（Q1）
- 只在寄信、订阅、账户操作时才需要登录；写日记永远不需要

## 产品风格基调

### 设计 DNA
- **克制**：不用渐变、不用粒子、不用动效炫技。能少一个元素就少一个
- **温柔**：圆角不要太大、配色低饱和暖调；动效用**不过冲的平滑曲线**，不弹、不晃
- **纸感**：米白底 + 衬线字 + 极轻纸张纹理
- **贴着实物**：先问「真实的纸、信、书会怎么动」，别照搬数码交互（抖动整理、果冻回弹）
- **像 Aesop**：高级感来自留白和材质感，不来自装饰

### 反例（千万别做）
- ❌ 闪屏放大图标 + 字带 emoji
- ❌ 按钮加渐变色 / 立体阴影
- ❌ 弹窗带「确认！」「真的吗？」感叹号
- ❌ 心情用 😊🥺😭 emoji（用文字 + 色点 / 线性图标）
- ❌ 「额度」「剩余 N 封」「升级解锁」这类计量词

### 文案语调
- 「今天」比「今天的笔记」好
- 「信箱还是空的」比「您还没有收到任何信件」好
- 「这周的信已经寄出了，青鸟习惯每周回一次」比「本周额度已用完」好
- 用「你」不用「您」

## 数据隐私（写进了隐私协议，实现必须相符）

- 日记正文、标题、照片、录音、天气、地点**不上传我们的服务器**，只在本机 + 用户自己的云
- 只有用户**寄信**时，**勾上的那几篇**日记的标题 / 正文 / 日期 / 心情经服务器转给大模型；**服务端不留存这些内容**，只存生成的回信
- 照片与录音任何情况下都不发送
- 后端只存：账户（手机号、昵称、笔友称呼）、登录绑定、来信、订阅记录
- 不收集设备标识符、不投广告、不做跨应用跟踪、不读通讯录与剪贴板
- 个人信息存储在中国境内（阿里云杭州）
