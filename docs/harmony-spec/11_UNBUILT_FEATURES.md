## 一、随绕排回退下线（2026-10-18 产品拍板）

**回退背景**：自研绕排引擎（WrapFlow，`headIndents/tailIndents` 逐行缩进路线）
真机接连撞上平台缺陷——① `orphanCharOptimization` × `strutStyle` 并存时恰好
2 行的段落 `Paragraph.paint()` 零输出（1/3/4 行正常，探针矩阵二分实证，查无
已知限制文档）；② `strutStyle.forceHeight` / `TextStyle.heightScale` 平台
实测均不生效，实绘行高 16.32vp ≠ 参数 20vp，照片几何逐行漂移（推走感+遮字），
只能以单字探针实测行高自愈；③ heading 样式经编辑器 doc 相邻块 `\n` 合并后
整段污染，拆段追修连做三轮。修一步漏两步、追修不见底，产品拍板三页全部回退
华为备忘录式（照片整行相纸卡 + 文字上下独立段，2.5/2.6 已真机 E2E 验收形态）。
