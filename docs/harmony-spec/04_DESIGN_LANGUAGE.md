# 04 · 设计语言

> 视觉规范 + 文案语调 + 反例。鸿蒙端**鼓励按 HarmonyOS Design 重新设计**，但精神必须一致。
>
> 最后核对：2026-10-12（色值逐个对过 iOS `Theme/*.swift`；主题改名为素笺 / 皮革 / 肯特；字号按 iOS 实际值改写）。

---

## 整体调性

**Aesop · 克制 · 纸感 · 温柔**

- 不用渐变、不用粒子、不用动效炫技
- 配色低饱和暖调，**不**用纯黑纯白
- 留白多过装饰
- 圆角偏小（4-8pt），不大圆角
- 阴影极淡

参考品牌（视觉灵感）：
- Aesop（产品页 / 包装）
- 苹果 Notes
- Bear（日记 App）
- 微信读书（信纸）

**反参考**（千万别走这风格）：
- Duolingo / 网易云音乐 / 抖音
- 任何用 emoji 装饰 UI 的产品
- 渐变色 + 高饱和 + 圆球泡泡

## 文案语调

### 总原则

> **像给一个老朋友写微信：温柔、克制、不油腻、不官方。**

### 好例 vs 坏例

| 场景 | ❌ 坏（避免） | ✅ 好 |
|---|---|---|
| 信箱空状态 | "您还没有收到任何信件，请先记录日记后再来查看" | "信箱还是空的" |
| 写日记占位 | "请输入您今天的所思所想..." | "今天，我想说..." |
| 删除确认 | "确定要删除吗？此操作不可恢复！⚠️" | "删除这篇日记" |
| 寄出之后 | "AI 正在生成回信，请耐心等待..." | "在路上" + 「回信会在三天内寄到你的信箱」 |
| 成功提示 | "保存成功！🎉" | （一般不提示；存草稿这种需要确认的才说「草稿已保存」） |
| 错误提示 | "出错啦！请重试 😢" | "信没能寄出：{原因}" |
| 来信节奏 | "本周额度已用完，升级会员解锁更多" | "这周的信已经寄出了。青鸟习惯每周回一次，下周再来寄吧" |

### 称呼

- iOS 文案**避免**用「您」（太官方）
- 用「你」「我」「咱们」（拉近距离）

### 标点

- 中文用全角标点（。，？！）
- 英文用半角标点
- 不要用感叹号炫情绪（除非真错了）
- 省略号用 `…`（单字符）不用 `...`

## 图标

### iOS 用 SF Symbols；鸿蒙怎么办？

鸿蒙端没有 SF Symbols。两个选择：
1. **引入 [Tabler Icons](https://tabler-icons.io/) / [Lucide Icons](https://lucide.dev/)** —— 线性图标，跟 SF Symbols 风格接近

**推荐 1**（线性图标），更国际化、风格统一。

## 动效

### 用的地方

- 页面切换：标准 push / modal（系统默认即可）
- 卡片点击：极轻按压反馈（scale 0.98）
- toast 进出：从顶部滑入 + 透明度（spring 0.35s）
- 🔴 **贴着实物、不过冲**：先问「真实的纸 / 书 / 信会怎么动」，用平滑曲线，不弹、不晃、不抖。
  iOS 被否掉过的：书架抖动整理模式、邮筒果冻回弹 —— 都别做
- 有分量的动作（投信、拆火漆信、拿书）配震动与声音，跟着动画时间轴走；系统开了「减弱动态效果」就不放动画
- 翻页阅读：左右切换（不强求 page curl）

### 不用的地方

- ❌ 启动动画**不要**炫技（极简 logo 渐显 0.3s 即可）
- ❌ 列表项**不要**有「飘入」动画
- ❌ 按钮**不要**有「彩色粒子」
- ❌ 心情选择**不要**有"弹出"动画

### 视差（Parallax）—— ❌ 已撤销，鸿蒙端不要做

iOS 端曾做过一个轻度 3D 视差（嵌入照片随陀螺仪偏移 ±6pt），**2026-08-06 整体删除**。
撤销原因写在这里，是为了避免鸿蒙端重蹈覆辙：

- **整张照片一起平移做不出纵深**。所有照片还共用同一个偏移量，一屏多图时全部同步晃动，
  观感是「页面在飘」而不是「有立体感」。真要做得分前后景、或用 3D 旋转 + 光泽跟随。
- 陀螺仪方案**在模拟器上完全无法验证**（无 device motion），只能真机盲调，迭代成本高。
- 它还有一堆静默失效的坑：低电量模式下默认不启动且无任何提示，用户只会觉得「开关是坏的」。

**结论：这是一个投入产出比很差的装饰性效果。** 同样的力气花在 Live Photo 上更值。

## 主题切换

ThemeManager 持有当前主题 id（偏好 `selectedTheme`），所有页面通过 `@Consume`（或等价方式）拿 token：

```typescript
setTheme(id: 'bamboo' | 'leather' | 'kent') { /* 存偏好、更新 token、按主题设应用明暗 */ }
```

- 切换**即时生效**，不重启
- 深色主题（皮革）让**整个 App** 切到系统深色，在应用级统一设，不逐个控件改（R-THEME-03）
- 但「选主题」这个动作要先弹**主题介绍**（R-THEME-04/05），不是点了就换

## App Icon

每个主题一张桌面图标（素笺 / 皮革 / 肯特），默认「跟随主题」，用户可在设置里固定某一张（R-THEME-06）。
图标是从三张启动封面里裁的同一套书本图形：**书本高度占画布 0.734，中心略偏下（Y 0.537）**。

鸿蒙**先确认平台能否动态换桌面图标**（Q5）。不能的话：只用一张主图标（素笺那张），设置里不出现「应用图标」。

## 截图（App Store / 华为应用市场上架用）

- 必须有「克制」的氛围
- **不要**加大字标语 "DON'T MISS OUT!" / "BEST DIARY APP!"

- 用 App 真实截图 + 极简文字 + 米白底
- 参考苹果 Notes / Bear / Day One 的 App Store 截图风格

## 反例 · 你做的鸿蒙版**绝对不能像**

```
❌ 启动页放大 logo 旋转 + 渐变背景 + "尺素 - 您的智能日记伙伴"
❌ 主页用卡片瀑布流 + 高饱和色块
❌ 按钮渐变 + 立体阴影
❌ 心情用 😊🥺😭 表情
❌ 列表项加用户头像
❌ 任何「分享到微信」按钮
❌ 弹窗用感叹号、emoji、彩色边框
```

如果你做出来感觉「太年轻 / 太娱乐 / 太活泼」—— 立刻停下来，往「成熟、克制、文学」方向退两步。
