## R-LANG · 多语言

| 编号 | 规则 |
|---|---|
| R-LANG-01 | 七种语言，顺序固定：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Español |
| R-LANG-02 | **没有「跟随系统」选项**。首启按系统语言定一个：中文看 script（Hant→繁）、无 script 看地区（TW/HK/MO→繁，其余简）；其余语言在名单里就用；**都不在 → 英语**（不是中文） |
| R-LANG-03 | 切换语言**当场生效、不重启、不丢导航栈**（不许用「重建整棵界面树」的办法） |
| R-LANG-04 | **所有用户可见文字七种齐全**，译文**直接取 iOS `Localizable.xcstrings`**，不要机翻（纸史文案、「杀青」等是专门写的，见 CHANGELOG 2026-09-16） |
| R-LANG-05 | 系统权限说明（相机 / 定位 / 麦克风 / 相册读写）也要七种，取 iOS `InfoPlist.xcstrings` |
| R-LANG-06 | App 名：简繁日 = **尺素**；英 = **memoir**；韩 = **그리움**；法 = **Déjà Vu**；西 = **Añoranza** |
| R-LANG-07 | 引号写在译文里，不在代码里拼；带名字的句子整句交给译文排（语序不同）。信件抬头：简繁 `致%@` / 英 `Dear %@` / 日 `%@へ` / 韩 `%@에게` / 法 `À %@` / 西 `Para %@`；没昵称用单独的「致」 |
| R-LANG-08 | 日期、数字格式跟 **App 语言**，不跟系统语言 |
| R-LANG-09 | 心情显示名按 key 查表（`mood.<key>`），库里存英文 key |
| R-LANG-10 | 默认日记本名（生活 / 读书笔记…）、「旅行 2」这种序号名是**用户数据**，不翻译 |

| R-THEME-04 | 主题选择页点一项**不立刻生效**，先弹「主题介绍」：主题名 → 图标预览 → 纸史正文 → 出处（默认收起）→ 分隔线 → 图标选项。**弹窗用目标主题的配色渲染**（弹窗本身就是预览） |
| R-THEME-05 | 弹窗底部：一句「这套主题也有一张对应的桌面图标。」+ 主按钮「一并更换图标」+ 次按钮「仅更换主题」。**不用「是的 / 否」，次按钮不是取消样式**。关闭弹窗 = 什么都不变。点已选中的主题仍弹窗。目标图标已生效时主按钮置灰「图标已是这一套」 |
| R-THEME-06 | 图标规则：默认「跟随主题」；手动选过就固定。「一并更换图标」= 回到跟随；「仅更换主题」= 把当前图标固定下来。**图标切换失败不回滚主题**，提示「主题已更换，图标没能跟着换」。目标与当前相同就不调用 |
| R-THEME-07 | 列表副标题是一句讲这种纸的话（允许两行，不截断）；列表底部「还在裁纸」 |
| R-THEME-08 | 桌面长按图标的快捷菜单有一项「应用图标」→ 打开 App 直达换图标页（返回一次回设置首页）。标题跟 **App 语言** |
| R-THEME-09 | 平台不支持换桌面图标 / 快捷方式时：整套图标相关入口不做，弹窗里图标那一段去掉。**先确认平台能力**（`09_OPEN_QUESTIONS.md` Q5） |
| R-THEME-10 | **官方/系统组件用纯官方样式，可读性靠系统自适应**：AlertDialog 等系统弹窗的按钮**不手涂 fontColor/backgroundColor/字体**，底色、正文明暗、按钮样式全交系统（R-THEME-03 联动保证明暗可读）；系统没提供的能力（如危险按钮红字）不硬造。页内自绘按钮仍逐主题配色：危险操作可用 = destructive 底 + 白字、禁用 = surface 底 + textTertiary 字（不许只用整块透明度降级），中性按钮 = accent 底 + 逐主题配对字色 |

## R-RICH · 图文正文编辑

| 编号 | 规则 |
|---|---|
| R-RICH-01 | 正文是**一整篇连续编辑**（不是一段段独立输入框拼起来）。三件事同时成立：自动折行、手动换行、随内容长高 |
| R-RICH-02 | 照片浮在所在段落左或右，**文字绕开照片排**；相纸样式与倾斜保留 |
| R-RICH-03 | 在光标处插照片：光标在段尾 → 挂到下一段开头；段首 → 挂这段；段中 → 断成两段，挂后一段开头 |
| R-RICH-04 | 录音插在光标所在段的**下面**，自成一段，不拆开这段话；插在全文末尾时光标移到录音下一行 |
| R-RICH-05 | 退格碰到照片 / 录音：**第一次选中，第二次才删** |
| R-RICH-06 | 点照片：靠左 / 靠右、设为封面、换相纸、删除；长按可拖到别的段落，松手位置的左右半边决定靠哪边 |
| R-RICH-07 | 格式：加粗、斜体、小标题（整段）、荧光笔。选中文字 → 菜单第一项「荧光笔」（已划过的显示「擦掉荧光笔」）；工具栏也有荧光笔键，未选中时对接下来打的字生效 |
| R-RICH-08 | 荧光笔颜色：素笺 `#F4D46A` 60%、皮革 `#B8862B` 55%、肯特 `#FFE15A` 70%；画法像记号笔，压住字的中下部、两头略圆 |
| R-RICH-09 | 老日记的录音不在正文里（`audioURLs` 有、正文没有）：显示时排在正文后面；**一打开编辑就补到正文末尾** |

| 编号 | 规则 |

| R-INK-04 | 补记（和日记不是同一天写的字）换一种墨色；整段都是同一天补的，段前标「补记 · 某月某日」（连续几段同一天只标第一段） |
| R-INK-05 | 干了的照片 / 录音可以取下：文件删掉，原处留一行「取下了一张照片 · 某月某日」/「删去了一段录音 · 某月某日」（`trace` 块） |
| R-INK-06 | 加粗、荧光笔等格式**随时可加**（是做标记，不是改写） |
| R-INK-07 | **整篇日记随时可以删** |

## R-BOOK · 日记本与书架

| 编号 | 规则 |
|---|---|
| R-BOOK-01 | 一篇日记**最多属于一本**；不选 = 只在「全部日记」。老数据 / 导入的「一篇在几本里」→ 名字去重后恰好一本留下，否则清空 |
| R-BOOK-02 | 日记本**数量不限**，「新建」入口永远在 |
| R-BOOK-03 | 名字判重键 = 去首尾空白 + 忽略大小写 + 忽略全半角。新建 / 重命名撞名：当场提示「已有同名的日记本」 |
| R-BOOK-04 | 书架 3 列，一层层书架板；「全部日记」固定第一格（象牙白亚麻），不能拿起、没有「…」菜单 |
| R-BOOK-05 | 书架顺序 = `sortOrder`（相同按 `createdAt`）；新建一律排最后 |
| R-BOOK-06 | **长按（≈0.35s）拿起一本**：同轴转过去约 32° 露出书脊（**要看得到书的厚度**）、轻轻浮起；拖动时原位**空着**，**其余书一动不动**（不晃、不让位）；拖到上下边缘自动滚；松手**先落进最近的格子**，其余书**这时才**轻轻挪开；落定后再转回正面。全程不过冲的平滑曲线，**不做桌面图标那种抖动整理模式** |
| R-BOOK-07 | 书脊颜色：满版照片封面 = 照片主色（压暗一点）；白框 = 纸色；贴照片 / 纯色 = 布面颜色 |

| R-DATA-05 | 🔴 **不许拿「系统登录了云账号」当「数据已同步」**。只有真实的同步成功事件才能对用户说「已同步」；没同步成功要明确警告「此刻卸载会丢失」并引导导出备份 |
| R-DATA-06 | 媒体同步用「事后对账」：以「库里引用了什么」为唯一依据补登记、补下载；不在每个写入点手工双写 |
| R-DATA-07 | 删除（日记 / 封面 / 孤儿清理）**连云端副本一起删**，否则下次同步又拉回来 |
| R-DATA-08 | 「清理残留文件」的引用表必须含：日记照片三件套、录音、**草稿**、**日记本封面**。显示「照片与录音占用」 |

## R-COPY · 文案语调

| 编号 | 规则 |
|---|---|
| R-COPY-01 | 像给老朋友写信：温柔、克制。用「你」不用「您」；不用感叹号炫情绪；省略号用 `…` |
| R-COPY-02 | 界面里不用 emoji；心情用文字 + 色点 / 线性图标 |
| R-COPY-03 | 寄信失败不说「生成」：「信没能寄出：{原因}」「日记内容未通过审核，这次没能寄出」 |
| R-COPY-04 | 不出现 SaaS 计量词：额度、配额、剩余 N 封、升级解锁 |
| R-COPY-05 | 成功一般不提示（存草稿这种需要确认的除外） |
