## 一句话

每篇新日记点 ✓ 存好以后，全屏弹出「写完了，此刻的心情是？」：
① 一根九档滑杆选个大概，中间一颗彩色细线缠成的心 —— 心情越好线越整齐、越差越乱，线一直在流，跟着手里的震动跳，可以用手指碰；
停在不愉快那几档，会带他跟着震动慢慢呼吸几轮。
② 点「下一步」，在这一档对应的 3～5 个词里选一个，点「完成」：心情（愉悦度 + 这个词）记进这篇日记，
日记列表、详情、阅读器、写作统计都显示它。

同时**删掉旧的心情标签**（平静、喜悦……12 个预设，连同写日记页、编辑页的选择器）和**所有印章**；写日记页只剩纯净的书写。

**写之前先选日记本**：点「写下今天的故事」，先弹出一排立在书架上的日记本，正中是一本大大的「全部日记」。
左右滑，像挑唱片那样一本本转过去：甩一下带着惯性一直转、慢慢停下，每过一本「笃」一声木头响、震一下；转着的时候点一下就停。
最底下「就写在这本里」，上面一行小字「想做一本新的日记？」当场建一本。选好了同一页换成写日记。有草稿就直接接着写，不问。

## 规则（取代 / 新增）

**取代 R-ENTRY-01**：写日记页**全屏**，左上返回箭头、右上 ✓。**只有点 ✓ 才算完成一篇**；正文全空时 ✓ 不可点。
点 ✓：**先把日记存好**（和 v1 完全一样），再全屏弹出心情页（R-MOOD-01）；心情页点「完成」后，心情页和写作页**一起**退出，回到进来的地方。
（日记在弹心情页**之前**就已经存好：心情页里 App 被杀掉，日记也不会丢。）

**R-MOOD-01 心情页什么时候出现**：只在「写日记页点 ✓ 存好一篇新日记」之后。存草稿、编辑已有日记、补记都不弹。
全屏，**不能下滑关掉**。第一步没有返回键；第二步左上角有返回（回到第一步改档位）；唯一的出口是第二步的「完成」。

**R-MOOD-02 九档**：愉悦度是 -1…1 的**连续**值（滑杆可以停在任意位置），九档只决定显示的档名、提示语和震动。-1…1 均分九段，第 k 档（0 起）的正中 = (k + 0.5) × 2/9 − 1。

| 档 | 愉悦度 | 档名 | 提示语 | 震动 | 呼吸轮数 |
|---|---|---|---|---|---|
| 0 | -1 … -7/9 | 跌入谷底 | 辛苦了。停在这里，握着手机，什么都不用做 | 慢心跳 48 次/分，力度 ×1.0 | 6 |
| 1 | -7/9 … -5/9 | 黯然神伤 | 辛苦了。先别急，停在这里，握着手机 | 慢心跳 51 次/分，×0.95 | 5 |
| 2 | -5/9 … -3/9 | 郁郁寡欢 | 没关系。停在这里，握着手机，慢一点 | 慢心跳 54 次/分，×0.9 | 4 |
| 3 | -3/9 … -1/9 | 闷闷不乐 | 有点闷也没关系。停一会儿，慢一点 | 慢心跳 57 次/分，×0.85 | 3 |
| 4 | -1/9 … 1/9 | 不悲不喜 | 平平常常，也是好好过的一天 | 两秒一下轻的，×1.0 | — |
| 5 | 1/9 … 3/9 | 怡然自得 | 有一点点好，也值得记下来 | 轻快两下，0.8 秒一组放慢到 0.9 倍速，×0.85 | — |
| 6 | 3/9 … 5/9 | 满心欢喜 | 这份好心情，值得多留一会儿 | 轻快两下，1.0 倍速，×0.9 | — |
| 7 | 5/9 … 7/9 | 神采飞扬 | 这样的日子，值得多记几笔 | 轻快两下，1.1 倍速，×0.95 | — |
| 8 | 7/9 … 1 | 心花怒放 | 真好。把这一刻好好收着 | 轻快两下，1.2 倍速，×1.0 | — |

（以后写进系统健康数据时存的是愉悦度本身；苹果「健康」把 -1…1 均分**七段**显示，九档落进它的七档：0 → 非常不愉快，1、2 → 不愉快，3 → 有点不愉快，4 → 中性，5 → 有点愉快，6、7 → 愉快，8 → 非常愉快。鸿蒙接华为运动健康时再定。）

**R-MOOD-03 页面布局**（从上到下）：标题「写完了，此刻的心情是？」（主题的标题字）→ 线团爱心（占满中间剩下的高度，左右各留 16）→
档名（衬线 28 号，正文色）→ 提示语（主题的标题字、**正文色**，居中，**固定留两行高**，换句子时下面的东西不跳）→
滑杆（左右各留 28）→ 滑杆两端小字「很不愉快」「很愉快」（说明文字色）→「下一步」按钮（主题强调色胶囊，白字）。
打开时滑杆停在正中（不悲不喜）。

**R-MOOD-04 滑杆**：胶囊轨道（主题的卡片底色）+ 8 道竖刻度（九档的分界）+ 白色圆形滑块（直径 36，轻阴影）。
手指在轨道上按下就跳到那里，拖动连续变化。无障碍：读作「此刻的心情」，值是档名，上下滑动一次跳一档（跳到那一档正中）。
档名和提示语换的时候淡入淡出（0.2～0.4 秒），不滑动、不弹跳。

**R-MOOD-05 震动**：心情页一出现就开始，离开就停。跟引擎共用（鸿蒙 `vibrator` 自定义振动，同一时刻只放一种节奏）。
强度、锐度都是 0…1（锐度低 = 钝、闷；鸿蒙按自己的频率参数换算，在真机上对着手感调）：

| 节奏 | 一组多长 | 组里的事件（时刻 秒：强度 / 锐度） |
|---|---|---|
| 慢心跳（不愉快四档） | 1.0 秒，按档放慢（倍速 0.8 / 0.85 / 0.9 / 0.95） | 0：瞬时 1.0 / 0.22 + 持续 0.1 秒 0.55 / 0.1；0.27：瞬时 0.7 / 0.18 + 持续 0.08 秒 0.35 / 0.08 |
| 轻（不悲不喜） | 2.0 秒 | 0：瞬时 0.35 / 0.3 |
| 轻快两下（愉快四档） | 0.8 秒，按档调速（0.9 / 1.0 / 1.1 / 1.2） | 0：瞬时 0.6 / 0.55；0.11：瞬时 0.45 / 0.7 |
| 呼吸引导 | 10 秒 | 一整段持续震动，基准 0.95 / 0.12，强度乘 `0.1 + 0.9 × 呼吸相位`（相位见 R-MOOD-06） |

- 每组循环播放；「力度 ×」是整组强度再乘的系数（见 R-MOOD-02 表）
- 换档：**每跨过一档**「嗒」一下（瞬时 0.65 / 0.85）；节奏种类变了就换节奏，同一种节奏只调速度和力度（不要重新开始一组）
- 碰心（R-MOOD-09）：瞬时 0.6 / 0.4
- 依据（**只能写在说明里，不能写成功效**）：比静息心率慢的「心跳」震动让人焦虑更低（Azevedo et al. 2017, *Scientific Reports* 7:2285）；
  震动呼吸节拍器（Miri et al. 2020, CHI）；慢呼吸时心率变异性升高（Laborde et al. 2022，223 项研究的荟萃分析）。
  「40 Hz」之类特定频率**没有**站得住的研究，不用

**R-MOOD-06 呼吸引导**：
1. 滑杆停在不愉快四档、**3 秒没动** → 开始。震动换成「呼吸引导」，提示语换成：吸气那 4 秒「跟着震动，慢慢吸气……」，呼气那 6 秒「……慢慢呼气」
2. 呼吸相位（0 = 呼尽，1 = 吸满）：一轮 10 秒，前 4 秒 `smoothstep(t/4)` 从 0 到 1，后 6 秒 `1 − smoothstep((t−4)/6)` 回到 0。震动强度和画面（心吸气时胀开 4.5%）用**同一条曲线**
3. 画面上的心从选的那档**褪向「不悲不喜」**：轮数按档（R-MOOD-02 表，3～6 轮，一轮 10 秒），进度 x = 已过时间 / 总时长，
   画面用的愉悦度 = 起点 + (0 − 起点) × (1 − (1 − x)²)（先快后慢：第一轮就看得出线在理顺、颜色在变）
4. 🔴 **只是画面**：滑杆位置、档名、以后记下来的，**都还是他自己选的那档**
5. 中途动了滑杆 → 立刻停止引导，回到滑杆那档的节奏；画面从褪到的地方用 0.8 秒平滑回到滑杆那档（不跳）；之后再停住 3 秒会重新开始

**R-MOOD-07 收尾**：最后一轮呼完（总时长是整数轮，收尾时正好呼尽）→ 心停在「不悲不喜」的样子、不再一胀一缩；震动换成「轻」那一种；
提示语换成「希望这短短的一会儿，让你好受了一点」，等他点「完成」。之后动滑杆 → 回到滑杆那档（同 R-MOOD-06 第 5 条）。

**R-MOOD-08 线团爱心**：直接画在页面纸色上（**不加框**，皮革等深色主题同样画在底色上），每秒 60 帧。画法见下面「爱心的画法」。

**R-MOOD-09 可以碰**：手指在爱心区域按下 / 拖动：
- 碰到哪一圈，那一圈附近的线**往前一涌**（比别的线流得快一阵，约 0.6 秒涌完，涌过去的不退回来）
- 碰的地方荡开一圈圈涟漪（约 2 秒散尽），整颗心轻轻一跳（里圈先、外圈后），手里「轻一下」（R-MOOD-05）
- 按住拖动：每划过 24 单位记一下，划过去留下一路涟漪；按住不动只算一下

**R-MOOD-10 减弱动态效果**（系统设置打开时）：线不流、不浮、心不跟震动跳、碰了没有涟漪和涌动（震动照有）、出场不逐根画；**呼吸引导照常**（一胀一缩、慢慢褪色都保留）。

**R-MOOD-11 文案边界**：心情页所有文字只陪着、不评判；🔴 **不许写疗效**（不说「会好的」「能缓解焦虑」「治愈」），收尾只说「希望……」。
心情页**不放求助热线**（产品定：多余）。

**R-MOOD-12 第二步：选一个情绪词**：第一步点「下一步」进来（呼吸引导、收尾状态照旧保留）。从上到下：
左上返回 + 标题「哪个词最贴近此刻？」→ 线团爱心缩小留在上面（高 220）→ 档名 → 小字「选一个最贴近的」→
这一档的 3～5 个词，胶囊排成居中的几行（标题字号）→「完成」（没选词时变淡、点不动）。
- **单选**：点一个选中（描一圈这一档的代表色、底上淡淡一层这个颜色），点另一个就换成另一个
- 回到第一步换了档：选中的词不在新的这一档里，就清掉
- 词用苹果「健康」的情绪标签（以后能原样写进健康数据），存英文 key；38 个分到九档，每个词只在一档出现：

| 档 | 词（key 简体中文） |
|---|---|
| 跌入谷底 | `hopeless` 绝望、`overwhelmed` 不堪重负、`scared` 害怕、`angry` 生气、`disgusted` 厌恶 |
| 黯然神伤 | `sad` 难过、`lonely` 孤独、`disappointed` 失望、`guilty` 内疚、`ashamed` 羞愧 |
| 郁郁寡欢 | `drained` 疲惫、`discouraged` 泄气、`frustrated` 挫败、`anxious` 焦虑、`jealous` 嫉妒 |
| 闷闷不乐 | `annoyed` 心烦、`irritated` 烦躁、`stressed` 压力大、`worried` 担心、`embarrassed` 尴尬 |
| 不悲不喜 | `calm` 平静、`peaceful` 安宁、`indifferent` 无感 |
| 怡然自得 | `content` 满足、`satisfied` 满意、`relieved` 释然、`grateful` 感恩 |
| 满心欢喜 | `happy` 开心、`joyful` 喜悦、`amused` 被逗乐、`hopeful` 满怀希望 |
| 神采飞扬 | `confident` 自信、`proud` 自豪、`brave` 勇敢、`passionate` 热情 |
| 心花怒放 | `excited` 兴奋、`amazed` 惊叹、`surprised` 惊讶 |

**R-MOOD-13 记下心情**：第二步点「完成」→ 把**第一步滑杆的愉悦度**（不是呼吸引导时画面褪到的）和选的词记到刚存好的这篇日记上（字段见「数据模型变化」），
然后心情页和写作页一起退出。存失败：日记本身已经存好，提示「这篇的心情没记上，日记已经存好了」，日志打完整错误。
心情一旦记下，这一版**不能改**（编辑日记页没有心情）。

**R-MOOD-14 日记上的心情**：没记心情的日记（这一版之前写的）什么都不显示。记了的：
- 标记的样子：这一档**代表色**的小圆点（直径 7）+ 档名；详情页再跟「 · 情绪词」。不加主题的宽字距（四字档名拉开就成了「郁 郁 寡 欢」）
- 代表色：跌入谷底 `#6B7394`、黯然神伤 `#7078A8`、郁郁寡欢 `#7380BF`、闷闷不乐 `#9E99DB`、不悲不喜 `#61BFD1`、
  怡然自得 `#85D670`、满心欢喜 `#F5CC4C`、神采飞扬 `#FF876B`、心花怒放 `#FA5C94`（各取自那一档的线团调色板）

**取代 R-HOME-03**：列表行：日期 + 星期、**右侧心情标记（圆点 + 档名）**、标题（单行）、正文前 60 字（两行）、日记本标签 + 此时此地。

**取代 R-ENTRY-15**：素笺主题的详情页是「和纸版式」（大日期数字，**没有印章**），标题下面一行心情标记（圆点 + 档名 · 情绪词）；

**R-PICK-04 手感**（位置的单位是「本」，取整 = 正中那本）：
- **拖**：书跟着手指走，拖 0.8 个封面宽 = 一本
- **甩**：松手速度 v₀（本/秒，最多 16）大于 0.5 → 带着惯性转。摩擦 = 粘滞（时间常数 τ = 1.3 秒）+ 恒定（a = 1.8 本/秒²），
  即 v' = −v/τ − a，自然停在 D = τ·v₀ − aτ·T 处（T = τ·ln(1 + v₀/(aτ))）。**一定正好停在一本上**：取离 D 最近的那本，
  把整条轨迹在时间上按 k = D / 实际距离压缩或拉长（τ → τ/k、a → a·k，起步速度不变，距离和时间都 ×1/k）；k 不在 0.3～4 之间就改成「转过去」。
  例：v₀ = 10 本/秒 → 转 8 本、2.2 秒停；轻轻一甩（2 本/秒）→ 1 本、1.1 秒
- **转着的时候按下去**：当场停在那里（产品定：随时点一下就停）；松手就近落到一本上
- **松手没什么速度**：就近落下，临界阻尼（时间常数 0.09 秒，约半秒落稳），**不过冲、不回弹**
- **停着的时候点旁边那本**：转到那本（缓入缓出，0.42 + 0.14 × 隔几本 秒，最多 1.2 秒）；**点正中那本 = 「就写在这本里」**
- 无障碍：整个转盘是一个可调节元素，读作「日记本」，值是正中那本的书名，上下滑动一次转一本，双击 = 就写在这本里

**R-PICK-05 每过一本响一声**：每当**另一本到了正中**（越过整数位置，或离它不到 0.02 本）：一声短促的木块「笃」+ 一下震动。
- 声音：`book_knock_1/2/3.wav`（iOS 仓库 `Memoir/Resources/Sounds/`，由 `Scripts/make_book_sound.py` 合成，`STYLE = "block"`，直接拿去用），**三份轮着放**；跟着静音键（静音时只有震动）。

## 爱心的画法（R-MOOD-08 的细节）

坐标：心形宽 2（x −1…1），上缘约 −0.73，心尖在 1.06，**y 朝下**。画布 W × H：`unit = min(W × 0.40, H × 0.36)`，
画布点 = (W/2 + x × unit, H × 0.5 − 0.165 × unit + y × unit)。

**心形曲线**：`x = 16 sin³t / 16`，`y = −(13 cos t − 5 cos 2t − 2 cos 3t − cos 4t) / 16`。每帧要取很多点，建议预先按 t 查表（4096 格线性插值）。

**190 根线**（固定随机种子，每次打开同一颗心；每根各自随机）：

| 属性 | 取值 |
|---|---|
| 圈 `scale` | 40% 的线 0.86～1.02（贴着轮廓，撑起心形），60% 的线 0.04～0.86 **均匀分布**（从外到正中填满 —— 是实心，不是中间空一个心形） |
| 一段多长 | 0.55～1.45 圈，起点随机；点数 = max(24, 圈数 × 170 × max(scale, 0.3)) |
| 流速 `flow` | 0.10～0.24 弧度/秒（26～63 秒走一圈），都往同一个方向 |
| 中心偏移 `cx, cy` | 各 ±0.025 |
| 自己的三道起伏 | 频率 2～4 / 5～8 / 9～13（一圈几个起伏），相位随机，游动快慢 0.15～0.45 |
| 打结 | 小圈频率 12～20，一阵一阵的频率 2～5，相位随机 |
| `stray` | −1～1（乱的时候往外或往里偏） |
| `float` | 自己慢慢胀缩的相位 |
| `response` | 0～1（滑动时跟得多快） |
| 颜色 | 调色板六色里随机一色；线宽 0.8～1.4；出场延迟 0～0.9 秒 |

**每帧每根线**：
- 这根线按哪个愉悦度画：`v = 慢慢跟上的愉悦度 + (滑杆此刻的 − 慢慢跟上的) × response`（「慢慢跟上的」= 滑杆值加 0.7 秒的平滑弹簧；所以滑动时有的线立刻变、有的慢半拍，像被拂过一样）。呼吸引导中两者都换成 R-MOOD-06 第 3 条的值
- `neg = max(0, −v)`，`pos = max(0, v)`，乱的程度 `mess = 0.25 − 0.2 pos + 0.75 neg`（很愉快 0.05、不悲不喜 0.25、跌入谷底 1）
- `wobble = 0.015 + 0.13 mess`，`curl = 0.07 mess^1.5`，`together = 1 − 0.85 mess`，`spread = 1 + 2.5 mess`，`radius = scale × (1 + 0.12 mess² × stray)`
- 胀缩 `swell = 1 + beat × (0.025 + 0.06 pos + 0.025 neg) + 0.045 × 呼吸相位 + (0.008 + 0.01 pos) × sin(0.6 time + float) + 0.03 × 碰一下的跳`
  - `beat`：震动节奏里每一下「很快涨满（40 毫秒）、再慢慢落（时间常数 0.16 秒）」，强度按 R-MOOD-05 的事件强度，乘本档力度；**用震动同一个时钟算**，画面才和手里对得上拍。里圈的线取「此刻」的值、外圈取 0.175 秒以前的值（按 scale 线性插），像一道搏动往外传
  - 碰一下的跳：碰后 `a = age − 0.12 × scale`，`a` 在 0～1 秒内时 `exp(−a/0.14) × min(1, a/0.03)`，多下相加、上限 1.5
- 流过的：`drift = flow × time + 涌动累计`（R-MOOD-09；碰在第几圈 `ring` = 到点 (0, 0.12) 的距离 ÷ 那个方向上心形边缘的距离，这根线涌 `0.9 × exp(−((scale − ring)/0.1)²) × (1 − exp(−age/0.6))`，`ring > 1.35` 不涌）

**每个点**（`a` = 点在线上的位置，`t = a + drift`）：
```
shared = 0.6 sin(3t + 0.5 time) + 0.4 sin(5t − 0.35 time + 1.3)          // 大家一起的波（整齐）
own    = 0.55 sin(f1 t + p1 + w1 time) + 0.3 sin(f2 t + p2 − w2 time) + 0.15 sin(f3 t + p3 + w3 time)   // 自己的（乱）
travel = sin(4t − 1.6 time + 0.6)                                        // 愉快时绕着心走的波
r = radius × (1 + wobble × (together × shared + (1 − together) × own) + 0.035 pos × travel) × swell
x = cx × spread + heart(t).x × r
y = 0.12 + cy × spread + (heart(t).y − 0.12) × r
// 打结（结跟着线走，所以用 a 不用 t）
burst = max(0, sin(burstFreq a + burstPhase + 0.3 time)),  c = curl × (0.25 + 0.75 burst²)
x += c cos(curlFreq a + curlPhase + 0.8 time),  y += c sin(curlFreq a + curlPhase + 0.8 time)
// 涟漪（每一下碰）：d = 到碰的点的距离，d² < 0.2 时
wave = 0.05 × exp(−d²/0.04) × exp(−age/0.7) × sin(18 d − 11 age)，沿「碰的点 → 这一点」方向推 wave
```
- 出场：每根线从出场延迟开始，0.6 秒内从头画到尾（缓出）
- 描边：圆头圆角，线宽见上，不透明度 `0.88 − 0.12 neg`
