## 一句话

2026-10-22 产品定的四件事：
1. 记录页**默认大屏**，列表是可选项；
2. 列表模式顶上加「全部日记 / 按月份」—— 按月份是一月一张卡片，点开才看到这个月的日记（同信箱的「按日期」）；
3. 日记本封面的「白框」改名**「杂志」**，纸的颜色能在 8 个预设色里选（原来只有米白一种）；
4. 8 个颜色的**顺序**改成象牙白、石灰、炭黑排前面。

## R-HOME-11 默认大屏（新增；补充 R-HOME-02）

- 没选过展示方式的（新装 App）一律**大屏**；列表是可选项。设置 → 外观 →「手记页」里**大屏排在列表前面**
- 选过的照旧记着（iOS 存在本机设置 `homeDisplayMode`）
- 鸿蒙还没上架，等于所有人一进来都是大屏

## R-HOME-05 空状态（取代 v1 R-HOME-05）

「暂无日记」+ 下面一行提示，**按写日记的入口在哪说**：

- 列表模式（入口是底部浮钮）：「点击下方按钮，开始书写今天的故事」（同 v1）
- 大屏模式（入口是导航栏右上「+」）：「点右上角的 ＋，开始书写今天的故事」

新用户默认大屏，第一眼看到的就是第二句（v1 那一句在大屏下指错了地方：大屏下面没有按钮）。

## R-HOME-12 列表：全部日记 / 按月份（新增；补充 R-HOME-02）

样子和 iOS 信箱的「按日期」归类是同一套（信箱那包 U05 还是草稿，这里写全了，照这里做）：

- 列表模式、有日记时，问候语下面一个两段的切换「**全部日记 / 按月份**」（胶囊形，同信箱顶上那个；选中的一段垫 14% 的强调色）。**记住上次选的**（本机设置，默认「全部日记」）；没有日记时不显示
- **全部日记**：原来的样子（一篇一张卡片，按年月分组、月份标题吸顶），不变
- **按月份**：一月一张卡片，最近的月份在上；月份写法同「全部日记」里的月份标题（「2026年10月」/「October 2026」）
  - 组头：月份 …… 篇数（**只写数字**，免得七种语言配单复数，垫一个浅色胶囊）· ›（展开时转 90° 朝下）；点组头展开 / 收起，0.25 秒缓入缓出
  - **没动过的时候只展开最近的那个月**；切到「全部日记」或大屏再回来就忘
  - 展开后组头下一道细线，一行一篇（最近的在上），行与行之间细线、左边空出日期那一栏：
    - 左边一栏 40 点宽：几号（Georgia 20 号）+ 星期缩写（跟 App 语言：「周二」/「Tue」）
    - 右边：标题一行（没标题用正文第一行、最多 30 字，再没有就「无题」）；有标题时下面再一行正文（第一行、最多 60 字）
    - 最右：心情徽标（同列表行）
  - 点一行进详情
- 卡片：圆角 16、卡片底色、1 点描边（同信箱）
- 读屏：组头读「{月份}, {篇数}」，提示「展开」/「收起」
- 这**不是搜索**：R-HOME-07（不做搜索、收藏）不变

## R-BOOK-14 版式（取代 v1 R-BOOK-14）

版式三种：**满版**（照片铺满，主页大图往下融进底色）/ **杂志**（原名白框：整张纸是这本选的颜色，照片嵌方形，书名在照片下）/
**贴照片**（亚麻布面贴一张带白边、四角相角的照片，书名烫在下面）。只有满版渐隐，其余干净收边。rawValue 不变（`FullBleed` / `Framed` / `TipIn`）。

杂志的纸和字（书架封面、编辑页预览、日记本主页大图都用这一套）：

| 颜色 | 纸（上 → 下的渐变） | 字 |
|---|---|---|
| 象牙白 | `#F8F3EA` → `#F4EEE2`（就是原来白框那张米白纸，一模一样） | 深棕 `#3D3428` |
| 其余 7 色 | 色值和白混 6%（上沿略亮）→ 色值 | 米白 `#F5F0E6`（同布面封面上的字） |

- 刊头的篇数（60%）、细线（35%）、书名都用这个字色；排法、比例不变
- 日记本主页大图（R-BOOK-09）的杂志版：同一张纸、同一个字色；底边收边（一点暗影 + 一道细亮线）按浅底处理的**只有象牙白**，其余按深底

## R-BOOK-13 封面编辑页（取代 v1 R-BOOK-13）

封面编辑页顺序：预览 → 封面照片 → 版式 → 颜色 → 副标题。颜色栏在**没照片**、版式是**贴照片**或**杂志**时出现：
没照片叫「或者选一种颜色」，贴照片叫「布面颜色」，杂志叫「**纸面颜色**」；满版没有颜色栏。移除照片时版式一并清掉。

## R-BOOK-07 书脊颜色（取代 v1 R-BOOK-07）

书脊颜色：满版照片封面 = 照片主色（压暗一点）；**杂志 = 纸色**（象牙白是 `#DCD3C2`，其余是这本的色值）；贴照片 / 纯色 = 布面颜色。
U03 写前选本子的转盘也跟这条走。

## R-BOOK-18 颜色的顺序（新增）

所有列 8 个颜色的地方（封面编辑页的颜色栏，以及以后再有的），一律按：

**象牙白、石灰、炭黑**、酒红、墨绿、普鲁士蓝、茄紫、琥珀棕

- 产品的理由：前三个最通用、最不容易出错，审美最柔和
- 只改显示顺序：rawValue、色值、新建日记本的默认色（墨绿）都不变
- 写日记时顺手建的日记本，iOS 给它「书架上用得最少的颜色（象牙白除外）、并列按这个顺序取」—— 所以并列时现在先给石灰（原来是酒红）
