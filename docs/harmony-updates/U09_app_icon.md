## 一句话

四套主题的桌面图标，从「笔记本 + 红书签」换成同一笔手写的「m.」：底色和字色就是主题列表里那两个色块，**平涂、不加任何玻璃 / 高光 / 投影**。
开场也跟着换：旧笔记本从启动封面上全部删掉，改成在封面中间**一笔写出这个 m.、落下句点**，配笔尖的「刷刷刷」和落点短促低沉的一声「砰」，约 1.2 秒进主界面。

## 改了什么、为什么

- 旧图标是一个通用的笔记本图形，四套只是换色，没有辨识度（2026-10-24 产品定重做）
- 新图标是用户自己写的一笔「m.」—— 像在纸上随手留下的一道字迹。字形照用户原图拟合，**笔画加粗到原图的 1.35 倍**（用户在原粗细和加粗之间选了加粗）
- 颜色**严格等于**主题列表的两个色块（v1 设置页主题列表左边那两块颜色），不另调：

| 主题 | 图标名（iOS） | 底色 | 字色 |
|---|---|---|---|
| 素笺（主图标） | `AppIcon` | `#FAF7F2` | `#8B7E6A` |
| 皮革 | `LeatherIcon` | `#1C1410` | `#C8A87C` |
| 肯特 | `KentIcon` | `#FFFFFF` | `#1A1A1A` |
| 极夜 | `PolarIcon` | `#000000` | `#8FA8BF` |

- 🔴 **平时不要一点玻璃感**：系统给图标加的玻璃、高光、投影一律关掉，字就是一块实心的颜色。
  只有用户把桌面切到系统的「透明 / 清透」外观时，才让系统拿字的形状去做透明效果，那时不带我们自己的颜色
- iOS 的实现备查：图标做成 Icon Composer 分层文件（底色一层 + 字一层，字层关玻璃）。
  不用单张 PNG 的原因：iOS 26 起系统会给「纯色底 + 单色字」的老式 PNG 图标自动套玻璃，字色被冲灰、边发虚（模拟器实测）。
  鸿蒙如果也有「系统自动给图标加效果」的机制，同样要关掉或绕开，验收看的是**字色和色值一致、边缘清楚**

## 规则

**R-THEME-13 桌面图标**（新增；取代 U04 **R-THEME-12** 表格里「桌面图标」「设置里的图标预览」两行，极夜的启动封面和邮筒那两行不变）：

- 每个主题一张，图形全部相同（一笔「m.」），只换两个颜色，色值见上表
- 构图：字在图标里的位置和大小照 iOS 素材，不要另行放大或挪动。字横向大约占图标宽度的 15%–89%、纵向 36%–69%（右下是句点）
- 平涂：字和底色都是单一颜色，无渐变、无纹理、无描边、无投影
- 系统的透明 / 清透 / 着色外观交给系统按字的形状生成，不单独出图
- 设置里的图标预览（v1 R-THEME-05 / 06 用到的那几张小图）同样换成新图：方形、不带圆角（圆角由界面裁）

v1 的 R-THEME-02（每个主题必须配图标）、R-THEME-05 / 06 / 08 / 09（换图标的交互和平台能力）都**不变**。

## 开场：一笔写出「m.」（2026-10-24 产品定）

旧笔记本（旧图标的图形）**从 App 里全部删掉**：启动封面上中间那本笔记本已经抹成底色，封面只剩主题底色和底部的「from Sinara」。
v1 04_DESIGN_LANGUAGE 里「图标是从三张启动封面里裁的同一套书本图形」那一段**作废**；同一文件里「启动动画不要炫技（极简 logo 渐显 0.3s）」这条，开场按本节做（产品定，写字本身就是「极简」的那一笔）。

**R-APP-10 开场写字**（**取代 R-APP-08**）：

- 按当前主题显示启动封面（`splash_<themeID>.png`，文件名不变、内容换了），封面淡入 0.2s；当前主题没封面就跳过开场（同 R-APP-08）；设置里「启动动画」关掉就不显示（同 R-APP-08）
- 封面出来 0.06s 后开始写：在封面中间把桌面图标上那个「m.」一笔写出来，颜色 = 当前主题的字色（R-THEME-13 的表）。时间表：

| 段 | 从哪到哪 | 时长 |
|---|---|---|
| 1 | 起笔 → 第一个尖（往右上的长斜线） | 0.142s |
| 2 | 第一个尖 → 底下的折角（往下） | 0.086s |
| 3 | 折角 → 第二个尖（往右上） | 0.113s |
| 4 | 第二个尖 → 收笔的小勾（往下再往右一勾） | 0.080s |
| 抬笔 | 挪到句点 | 0.07s |
| 句点 | 笔尖点下去，墨在这段时间里从 0.4 倍洇到原大（ease-out，**不回弹**） | 0.05s |
| 停 | 写好的字停一下，让人看清再进（0.15s 时用户觉得点完立刻就进去了） | 0.35s |
| 淡出 | 整层淡出进主界面（R-APP-08 是 0.3s，这里缩到 0.25s） | 0.25s |

- 段内快慢：段内走过的比例 = τ − 0.85·sin(2πτ)/(2π)（τ = 段内时间 0…1）—— 两头慢、中间快，到尖角几乎停住，像真写字。四段之间不停顿
- 字的画法和桌面图标同一份数据：四段三次贝塞尔当中线、沿中线密密地盖圆（圆半径沿弧长插值、整体 ×1.35），写到哪画到哪，笔尖处补一个圆让过程连续。控制点、半径照抄 iOS 的 `Memoir/Views/Splash/HandwrittenMark.swift`（和 `Scripts/make_app_icon.py` 的 `STROKE` 是同一份）
- 位置：字（含句点）的宽度 = 封面显示宽度的 44%，中心在封面显示高度的 45%（就是原来笔记本的位置），跟着封面走，不跟屏幕
- 声音：从写第一笔那一刻开始放 `splash_write.wav`（已按上面的时间表合成好：四声「刷」+ 0.49s 处一声短促低沉的「砰」，共 0.69s。「砰」像写完把笔头往纸上一按：几十毫秒就收住，不要清脆的「嗒」（第一版脆，用户否了），也不要拖长的「咚——」（第二版，用户否了））。**跟随静音键**（静音时只有画面）、不打断用户正在放的音乐
- 点任意处跳过（同 R-APP-08），跳过时声音在淡出的 0.25s 里一起淡掉
- 系统开了「减弱动态效果」：不写、不出声，直接显示写好的字，停 0.6s 后淡出
- 主界面在开场期间就在底下建好（同 R-APP-08）

## 任务卡

### U09-1 换桌面图标

- **目标**：四个主题的桌面图标和设置里的预览换成手写「m.」
- **先读**：本包「规则」「素材」两节；v1 06_RULES 的 R-THEME-02 / 05 / 06 / 09；U04 R-THEME-12
- **要做**：用上面的素材替换四套图标（前景 `m.png` + 纯色背景）和四张预览图；平台若有给图标自动加的光效 / 质感，关掉
- **不要**：不改换图标的交互和设置项；不自己重画或描字；不改邮筒插画（开场另见 U09-2）
- **验收**：真机桌面上逐个切四个主题图标：字色、底色和上表一致（取色核对），字边缘清楚、没有玻璃 / 高光 / 投影；句点完整；设置里四张预览和桌面一致

### U09-2 开场写字

- **目标**：开场从「静态封面 0.7s」换成「封面上一笔写出 m.、落点、配声音」
- **先读**：本包「开场」一节（R-APP-10）；v1 06_RULES 的 R-APP-08；v1 03_USER_FLOWS 第 246 行那步启动流程
- **要做**：换四张启动封面；照 R-APP-10 的时间表和画法写字（字形数据照抄 `HandwrittenMark.swift`）；放 `splash_write.wav`（跟随静音键、混音）；跳过、减弱动态效果两种情况
- **不要**：不加回弹、缩放、描边这类效果；不另做动画曲线；声音不要在静音时响
- **验收**：真机冷启动四个主题各看一次：字在原来笔记本的位置、颜色同桌面图标；四声「刷」和四笔对得上、「砰」和句点同时、短促低沉；从封面出来到主界面约 1.2s；点完句点能看清写好的字再淡出；开静音没声音；点一下立刻淡出；「启动动画」关掉就直接进
