## 一句话

鸿蒙上**不用 SF Symbols**：iOS 用苹果 SF Symbols 的地方，鸿蒙一律换成系统自带的 **HarmonyOS Symbol**（名字已逐个对好），只有尺素自己画的（设置首页那套线条、火漆印、手写 m.）给图片；设置下面二十几页逐页写清楚长什么样、点了怎么弹出来、弹在哪 —— 包括「位置精度」那个 市 / 区县 / 街道 的小菜单，以及天气地点在写日记页、读日记时的样子和「选择地点」弹窗。

## 改了什么、为什么

- **2026-11-07 用户要求**：把设置页和其他所有出现图标的地方，像给鸿蒙做设置首页那样单独抠出来做一份汇总，包括尺素会员那枚火漆印的效果；设置二十几页每一页都写详细，天气、位置弹出来是什么、在哪个位置出现都要写；图标单列一份文档，以图片的形式插进设置页的文档里
- **图标的来源（用户定）**：🔴 苹果的 SF Symbols 授权只许用在苹果平台，**鸿蒙不能截、不能描、不能用 SF Symbols 的素材**。所以：
  - iOS 用 SF Symbols 的地方 → 鸿蒙用系统的 HarmonyOS Symbol（`SymbolGlyph($r('sys.symbol.xxx'))`），跟着系统字号、粗细、深浅色走
  - 尺素自己画的 → 给图片（设置首页那批 U10 已交付；本包新出火漆印）
  - **取代 v1 `04_DESIGN_LANGUAGE.md`「图标」一节**：那里推荐引入 Tabler / Lucide、附了两张 Tabler 对照表，现在不用了；那节最后一行「设置分组图标按 HarmonyOS 风格自选」也由 U10 的图片取代
- **名字怎么来的**：用户给了华为官方图标库（[developer.huawei.com/consumer/cn/design/harmonyos-symbol](https://developer.huawei.com/consumer/cn/design/harmonyos-symbol/)）。iOS 侧拿那一页加载的名字表（v2.3，534 个，带中文名）和图标字体 `HMSymbol.ttf`（4800 多个字形，字形名就是 `sys.symbol` 的名字）一个个对：能在图标库网页上找到的优先；网页没列、字体里有的 35 个在 ICONS.md 里标出来了，要在 DevEco 里核对
- **火漆印**：会员那枚印上压的是**用户昵称的首字**，每个人不一样，做不成一张固定的图 —— 给空白印面 + 压字的规格 + 样张；会员款旁边的小标记固定压「素」，直接给图
- **v1 的 Q7（天气标识的跨端词表）本包定下来**（R-PLACE-08）
- v1 已有的设置规则（R-SETTINGS、R-THEME、R-DATA、R-PLACE、R-ACCOUNT）**内容都不变**，本包只补 v1 没写到的「长什么样、怎么弹出来」，以及上面三件

**R-ICON-03 火漆印**（新增）：

- 蜡的颜色四套主题都一样（深红），不跟主题
- **压字的印**（设置首页「尺素会员」那行 26vp、付费页顶上 68vp、会员页顶上 60vp）：放空白印面 `img_wax_seal_blank.png`，上面叠两层同样的字 —— 规格（印的直径 = 图片边长 × 68⁄86、字号 = 直径 × 0.32、衬线半粗、底层黑 28% / 上层白 22% 往右下偏 直径 × 0.012）在 `ICONS.md`「火漆印」一节
- **压什么字**：昵称去掉首尾空白后的第一个字；拉丁字母大写；没昵称、没登录、或第一个字是表情 / 符号 / 数字 → 「素」。印面的字不翻译；读屏念「尺素会员」
- **会员小标记**（固定「素」，**只给还不是会员的人看**）：直接用 `img_member_badge.png`，用在哪、多大见 `ICONS.md`（相纸样式、选相纸、封面版式、情绪小结卡片、读完来信页底那一行）
- 用 `sample_wax_seal_*.png` 样张验收

**R-SETTINGS-12 二级页的样子**（新增；配色仍是 U10 的 R-SETTINGS-08）：

- 顶上：左上角圆形返回钮 + 正中一行**小标题**（主题小号字、字距拉宽、次要文字色），不用大标题
- 分组卡片；行首 HarmonyOS Symbol 14vp、次要文字色、占 20vp 宽、和文字间距 10vp，**不套框**（套框只在首页，U10）；右边是当前值（第三级文字色）/ 开关（开时强调色）/ `chevron_right`
- 跟着选项变的说明是卡片里单独一行小字；组下面的说明是组外的灰色小字
- 每一页的行、顺序、右边显示什么、存哪、默认值：照 `SETTINGS_PAGES.md` 第四 ~ 十五节

**R-SETTINGS-13 弹出方式**（新增）：

- 每一处用 `SETTINGS_PAGES.md` 写的那一种，**不要换**：推入 / 半屏弹窗 / 全屏盖 / 行尾小菜单 / 小气泡 / 屏幕中间的弹窗 / 底部确认 / 系统文件选择器 / 系统分享 / 顶部提示条 —— 各自在鸿蒙用什么组件见那份第二节的表
- 几处容易做错的：
  - 「手记页」「位置精度」「封条提醒天数」是**行尾小菜单**，锚在行尾的值上，不推入新页、不用底部弹窗
  - 「时间」是行尾胶囊下方的**小气泡**，里面滚轮，滚完即存，没有「确定」按钮
  - 「笔友名」是**行内直接输入**，不弹窗；「昵称」是**屏幕中间的输入弹窗**
  - 付费页是**全屏盖**（往下拖关不掉）；登录、导出、导入、主题介绍是**半屏弹窗**（往下拖能关；导入进行中不能拖关）
  - 退出登录、清理残留文件是**底部确认**；导入时同名日记本是**屏幕中间的弹窗**
  - 「导入备份」点了**直接弹系统文件选择器**，不先进一页
  - 主题介绍：**先关弹窗、再换主题和图标**

**R-PLACE-06 地名按精度怎么拼**（新增；补 v1 R-PLACE-02）：

| 档 | 拼法 | 例子 |
|---|---|---|
| 市（默认） | 城市；取不到（直辖市常见）用省 / 直辖市那一级 | 广州市 |
| 区县 | 城市 + 空格 + 区县；没有区县只要城市 | 广州市 天河区 |
| 街道 | 有地标 / 店名就只用它；否则 区县 + 空格 + 路名门牌；再取不到 → 城市 + 区县 → 城市 | 广州塔 / 天河区 天河路385号 |

- **每一档取不到都往上一级退，绝不存空字符串**
- 改了精度只影响之后写的日记（存下的地名是一段文字，不回头重算）
- 关了「记录位置」：不取地名，**天气照取**

**R-PLACE-07 选择地点弹窗**（新增；补 v1 R-PLACE-01）：

- 写日记页点「此时此地」胶囊 → **半屏弹窗**「选择地点」，左上角「取消」
- 第一组：「不显示位置」；「当前位置」（大字是按精度拼好的地名，小字「当前位置」）
- 第二组「附近」：当前位置 **500 米**内的地点，**从近到远**；每行小字「距离 · 区 路」（不到 1 公里写「102 m」，否则「1.2 km」）
- 搜索：以当前位置为中心 **5 公里**、按关键字，**停止输入 300 毫秒后**才搜；组名变「搜索结果」；搜不到显示「没有匹配的地点」，**不算出错、不弹提示**
- 选中的那行右边打勾；点任何一行：轻震一下、弹窗马上关、胶囊换成选的
- 存进日记的：当前位置 = 拼好的地名；不显示位置 = 不存地名（天气照存，胶囊尾巴换成「不定位」图标）；附近地点 = 那个地点的名字

**R-PLACE-08 天气标识 `weatherCode`**（新增；**定下 v1 Q7**）：

- 跨端词表就用 **SF Symbols 的名字**（iOS 本来就存它：`sun.max`、`cloud.sun.rain`、`moon.stars`…；旧日记还有 `clear` / `rain` 这类代码）。它只是一段字符串，鸿蒙**不画 SF Symbols**，只认名字
- 鸿蒙**显示**：按 `ICONS.md` 第三节的表，从上往下看名字里含不含那个词，先匹配的先用；一个都不含 → `cloud`
- 鸿蒙**写**：把自己天气服务给的现象写成表里那一行对应的 SF Symbols 名（晴天白天 `sun.max`、夜里 `moon`、小雨 `cloud.drizzle`、雷阵雨 `cloud.bolt.rain`…）；iOS 读到不认识的名字会退成一朵云，不会出错
- 温度 `weatherInfo` 照旧是「26°」这样的文字

**R-PLACE-09 此时此地显示在哪**（新增）：

- 一个标记：天气图标 + 温度 +「·」+ 小定位图标 + 地名；**缺哪项少显示哪项**，只有地名时不要「·」，全空整个不显示；图标比那一行的字小一号、小定位再小 1，颜色跟那一行的字
- 出现在：写日记页（日期下、标题上的胶囊，有五种状态，见 `SETTINGS_PAGES.md` 第十二节）、记录页列表每一行的最后一行（靠右）、大屏卡片文字区最下面、日记详情（素笺主题在星期后面「|」再接；其他主题在日期下面单独一行）、精装 PDF 每篇篇末一行「地名 · 温度」（不画图标）、寄出的信的邮戳地名
- **编辑已有日记时不能改**此时此地

- **目标**：鸿蒙 App 里所有图标都来自 HarmonyOS Symbol 或尺素给的图片，没有 Tabler / Lucide / SF Symbols 的痕迹
