## 一句话

鸿蒙那边写代码的 agent（DevEco）**没有视觉，看不见图片**。所以从本包起，给鸿蒙的规格一律用**文字和代码**写：长相、位置、颜色、大小都写成字和数（颜色写十六进制，组件给 ArkTS 片段）。U19 的两份长文档已经照这个改好：去掉了全部插图，火漆印改成一段照着画的 ArkTS 代码，验收改成按字逐条核对。

- **2026-11-07 用户指出**：DevEco 没有视觉功能，只能照语言和代码描述去做。U19 交付的两份长文档在每一行旁边插了图标小图，设置各页配了 26 张截图，有几处还写着「截图右边那个小菜单」；火漆印要「对照样张验收」。agent 看不见这些图，这几处等于没写

- U19 已交付、冻结，所以按规矩在本包里更正。两份长文档（`HarmonyAssets/` 下，不是更新包本身）已经直接改好，鸿蒙重新拉 iOS 快照就是新版

## 规则

**R-DOC-01 给鸿蒙的规格只用文字和代码**（新增；适用于本包起的所有更新包，以及 U19 的两份长文档）：

- 长相、位置、弹出方式、颜色、字号、大小、间距：写成字和数。颜色写十六进制（带透明度的写 ARGB，如 `#47000000` = 黑 28%），大小写 vp
- 自己画的部件，能用代码画的给 **ArkTS 代码**（照 iOS 源码一一对应）
- 图片只有两种用途，**都不是规格**：
  1. **拿来就用的资源**：拷进 `resources/base/media`，按文件名引用（`$r('app.media.文件名')`）。agent 只需要知道文件名和显示尺寸，不需要看它长什么样
  2. **给人对照的**：iOS 截图、`preview.html`。agent 不用打开；写着「和截图对比」的验收是**给人（陈总）做的**，agent 按文档里的文字条目自查
- 文档里不写「如图」「截图右边」「见样张」这类只有看图才懂的话
