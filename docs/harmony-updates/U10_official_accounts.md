## 一句话

设置首页照苹果「设置」的样子重排：大标题；最上面一张账户卡（手写 m. 头像 + 名字 + 一行说明）；页面底比卡片深一档，一组一组分得出来；每行前面的图标还是原来那套单色线条，套一个细线方框；最底下一组「关注我们」（小红书 / 抖音 / 微博，一行一个）；「给我们评分」的图标换成应用商店的「A」。

## 改了什么、为什么

- **2026-10-24** 用户想在 App 里找到我们的官方账号。用平台**自己的单色小 logo**（小红书的字标、抖音的音符、微博的眼睛），**不用方方正正的 App 图标**（用户：很丑）
- **2026-10-26** 用户要设置页沿用苹果「设置」的分层风格。几处具体的决定：
  - **头像**：用户原想像 Apple / 华为账号那样显示账号头像。苹果不给 App 读 Apple 账户的头像（Apple 登录只给名字和邮箱），用户定**不放照片、两端统一显示尺素的手写 m.**。🔴 **鸿蒙即使华为账号能拿到头像也不用**，两端保持一致
  - **图标**：试过苹果那样每格一种底色的小方块，用户不要（「原来的比较简洁」）—— **保留原来的单色线条图标和颜色，只在外面加一个细线框**
  - **「关注我们」**：本包前一版草稿是页底一行「关注我们 ｜ 三个 logo」，用户嫌不好看，改成和上面各组一样的一组行。前一版草稿没交付，这里直接改写
- 评分不放进「关注我们」：上面「给我们评分」那一行就是。那一行的图标**从五角星换成 App Store 的「A」**
- **分大陆版和全球版**：两边用的社交平台不一样。现在只做大陆版；全球版换成 X、Instagram、Facebook、YouTube，账号还没给

**R-SETTINGS-10 账户卡**（新增；R-ACCOUNT-03「未绑手机号的警告留在一级页」不变）：

- **头像** 60pt 圆：底色 = 主题列表里这套主题的底色色块、0.5pt 细边（主色 8% 不透明度）、中间是**手写 m.**（U09 的同一份字形，**静止、不放书写动画**），宽 = 头像的 60%，墨色 = 色块里的字色
- 头像右边：名字（title3、半粗；有昵称用昵称，没有用脱敏手机号，都没有显示「已登录」），下面一行「账号、手机号与登录方式」（subheadline、次要文字色）；点了进账号页

- **没登录**：同样的头像 +「登录 / 注册」+「登录后才能收到笔友的回信」+ `>`，点了弹登录
- **不显示账号平台的头像**（理由见上）

**R-SETTINGS-07 关注我们**（新增）：

- 设置首页**最后一组**，组头「关注我们」（系统组头样式）
- **一行一个平台**：R-SETTINGS-09 同款的方框，里面放平台的单色小 logo（主题的次要文字色，宽不超过 22pt；高：小红书 8.5pt、抖音 18pt、微博 15pt —— 字标是扁的要矮一些才和别的一样「重」）→ 平台名（系统正文字号）→ 右侧 ↗

## 任务卡

### U10-1 设置首页重排

- **目标**：设置首页是大标题 + 账户卡 + 分组卡片，页面底和卡片分得开，每行图标套细线框；设置下面的各页同样分层
- **先读**：本包 R-SETTINGS-01、08、09、10；v1 设置首页（6.x 设置）、R-ACCOUNT-03
- **要做**：按新顺序分组；页面底 / 卡片按主题取色；行首图标套方框（不填色、原来的颜色）；账户卡换成 m. 头像 + 名字 + 说明，未绑手机号时组里多一行红点提醒 + 组下警告
- **不要**：不显示华为账号头像；不给每行图标配不同颜色；不改二级页的内容和顺序（只换底色）；不把未绑手机号的警告收进二级页
- **验收**：四个主题各截一张设置首页，和 iOS 对比：分组看得出、图标颜色和 v1 一样只多了框；登录 / 没登录 / 没绑手机号三种账户卡都对

### U10-2 设置页加「关注我们」

- **目标**：设置首页最后一组是「关注我们」，一行一个平台，点了进我们的官方主页；「给我们评分」的图标换成应用商店的「A」
- **先读**：本包 R-SETTINGS-07、「账号和链接」；v1 评分入口的规则
- **要做**：放三行（方框 + 单色 logo + 平台名 + ↗）；每个按「装了进 App、没装进网页」打开；名单按版本区分，空名单整组不出；换评分那一行的图标
- **不要**：不用各平台的方块 App 图标；不给 logo 上平台的品牌色
- **验收**：真机上装着 / 没装小红书、抖音、微博各点一次：装了直接到我们的主页，没装开网页且能看到主页；读屏念出平台名；切四个主题 logo 颜色跟着变
