> 基于：**v1**（只依赖 v1 的主框架和日记数据；配色借 U10 的 R-SETTINGS-08，U10 没做也能先用主题卡片色）｜ 状态：**草稿**（iOS 已做、等用户真机看过定稿）

## 一句话

设置 → 外观里打开「搜索日记」后，底部标签栏右边多一个**系统原生的搜索入口**（默认关，关着就是原来四个 tab）：输入关键字，搜所有日记的标题和正文，结果列出日期、日记本、标题和关键字附近的一段原文（关键字高亮），点进去就是那篇日记。

## 改了什么、为什么

- 用户要能按关键字找回写过的日记（2026-10-26 产品定），**搜索栏用系统原生的**
- 补充 v1「1.6 主框架」的四个 tab：**记录 / 日记本 / 邮筒 / 设置四个不变**，另加一个搜索入口
- iOS 的做法：标签栏的「搜索」角色 tab，单独一颗放大镜在最右边，点开后在底部展开搜索框、键盘直接弹起
- **入口默认不出现**（2026-10-27 用户定）：设置 → 外观加一个「搜索日记」开关，打开了底栏才多那颗圆；关着底栏和 v1 一模一样

## 规则

**R-SEARCH-01 入口**：底部导航**最右边单独一颗圆形的搜索按钮**（放大镜），和四个 tab 在同一行、但**不并进那条标签栏**，不算第五个 tab（用户定，2026-10-27）。
- 点这颗圆：直接出搜索框、键盘弹起，可以马上打字；搜索框旁的 ✕ 收起搜索、回到点之前的那个 tab
- 鸿蒙用**系统原生的搜索框组件**，入口和搜索框的样子按鸿蒙原生，不要自己画；只要做到「单独一颗、不并进标签栏」「点了直接能打字」
- 页面标题「搜索」，搜索框占位「搜索日记」
- iOS 备查：iOS 27 默认会把搜索 tab 并进标签栏当第五格，iOS 加了一句「点搜索 tab 就激活搜索」才保持单独一颗圆（`ContentView.swift` 末尾的 `SearchTabStandsApart`）

**R-SEARCH-06 开关**：设置 → 外观，「启动动画」下面一行「搜索日记」（放大镜图标 + 开关），**默认关**；这一组下面的小字「打开后，底栏右边多一个搜索按钮，可以按关键字找写过的日记。」。
- 关：底部导航就是 v1 的四个 tab，没有搜索入口
- 开：当场在四个 tab 右边多出搜索那颗圆（不用重启）；再关掉当场消失
- 存在本机设置里（iOS `UserDefaults` 的 `showSearchTab`），**不进备份包、不同步**

**R-SEARCH-02 搜什么**：每篇日记的 `title` 和 `content`（v1 05 数据模型：`content` 是去掉划掉的字之后的纯文字，「搜索读它」本来就写在那里）。**不搜**心情、地点、天气、日记本名、照片、录音

**R-SEARCH-03 怎么算匹配**：

- 不分大小写、全角半角、变音符号（é = e）
- 空格（含全角空格）隔开的几个词**都要出现**才算（每个词在标题或正文里任一处出现即可）
- 敲字停 **0.15 秒**再搜，不每敲一下算一次
- 全在本地，**不联网**
- 写了新日记 / 删了日记，结果跟着刷新

**R-SEARCH-04 结果列表**：

- 按日期**从新到旧**；列表上方组头「N 篇日记」
- 每条一行：
  - 左边 40pt 宽一栏：日（Georgia 20pt、主文字色）+ 下面月份缩写（标签字体、第三级文字色）
  - 右边：标题（正文字体、一行；没标题就不显示这一行）→ 正文片段（说明字体、次要文字色、最多 3 行）→ 「2026年10月 · 日记本名」（标签字体、第三级文字色；没有日记本只写年月）
- **正文片段**：正文里**最先出现的那个关键字**往前留 14 个字，总长约 74 个字，前后被截断的地方加「…」，换行压成空格。正文里没有关键字（只有标题命中）时，显示正文第一行非空的文字，最多 60 个字
- **高亮**：标题和片段里每一处关键字都用主题强调色 + 加粗（几个词挨着或重叠时并成一段）
- 点一条进那篇日记的详情页，返回回到结果列表（搜索词保留）
- 页面底 / 卡片配色同 U10 的 R-SETTINGS-08

**R-SEARCH-05 空状态**（系统的「无内容」样式，放大镜图标）：

- 还没输入：「搜索日记」+「搜标题和正文里写过的字」
- 没搜到：「没有找到」+「没有含「关键字」的日记」（关键字是用户输入的原文，去掉首尾空格）

## 任务卡

### U12-1 搜日记

- **目标**：底部导航最右边有搜索入口，输入关键字能找到含这些字的日记，点进去看原文
- **先读**：本包 R-SEARCH-01 ~ 06；v1 05 数据模型里日记的 `title` / `content`；v1 1.6 主框架
- **要做**：外观页加「搜索日记」开关（默认关）；开了才加入口和原生搜索框；按 R-SEARCH-03 在本地匹配；结果列表按 R-SEARCH-04（片段、高亮、日期栏、日记本名）；两种空状态
- **不要**：不把搜索并进标签栏、做成第五个普通 tab；不自己画搜索框；不联网搜；不搜心情、地点、日记本名
- **验收**：新装默认只有四个 tab；外观里打开开关，当场多出搜索按钮，关掉当场消失；搜索按钮单独一颗、和四个 tab 同一行；点了直接能打字，✕ 回到原来的 tab；一篇日记正文里有「Check」，搜「check」能找到且高亮；搜两个词时只出两个都含的；划掉的字搜不到；全角字母和半角字母互相搜得到；删掉那篇后结果马上少一条；七种语言下空状态和组头文字都对
