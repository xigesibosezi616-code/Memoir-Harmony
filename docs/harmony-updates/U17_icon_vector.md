# U17 · 图标素材换成矢量（外观不变）

> 基于：**v1 + U09**（只改 U09「素材」一节指向的文件）｜ 状态：草稿
> 本更新包**自成一体**：鸿蒙团队只看这份 + U09 即可。

## 一句话

桌面图标和设置里的图标预览，图形、构图、颜色**一点没变**，只是素材从位图换成了矢量：
原来字层是 1024 的 PNG、设置页预览只有 192 像素，放大就糊、有锯齿（2026-11-07 申请版权时发现）。

## 改了什么、为什么

- 字形本来就是数学定义的（中线四段贝塞尔 + 圆头笔的粗细，见 `Scripts/make_app_icon.py`），现在直接从同一份数据算出矢量轮廓：
  一笔「m」是一整块轮廓，句点是一个正圆
- 核对过：矢量渲染成 8192 再缩回 192，和旧的 192 预览逐像素差 0.03%；iOS 编译出的静态图标和旧的差 0.02%
- 另出了四套**母版**放在仓库根目录 `Branding/AppIcon/`，申请版权、印刷、给设计师都用这个

## 规则

U09 的 **R-THEME-13 不变**（每个主题一张、图形相同、只换两色、平涂、构图照 iOS 素材）。

**取代 U09「素材」一节的表格**：

| 素材 | iOS 仓库里的文件 | 说明 |
|---|---|---|
| 字（前景层） | `Memoir/AppIcons/<图标名>.icon/Assets/m.svg` | 矢量，标称 1024×1024，**透明底**，字已经是该主题的字色。四个文件图形相同、颜色不同 |
| 底色（背景层） | `Memoir/AppIcons/<图标名>.icon/icon.json` 里的 `fill.solid` | 纯色，色值同 U09 的表（没变） |
| 设置里的图标预览 | `Memoir/Assets.xcassets/AppIconPreview_{Bamboo,Leather,Kent,Polar}.imageset/*.svg` | 矢量，底色 + 字合成好的方图，标称 64×64 |
| 母版 | `Branding/AppIcon/{素笺,皮革,肯特,极夜}.svg` / `.pdf` | 底色 + 字的方图（不带圆角），矢量，要多大的位图自己导；在 iOS 仓库里，不随快照给鸿蒙，要的话找 iOS 负责人 |
| 生成脚本 | `Scripts/make_app_icon.py` | 一次出上面全部；改颜色或加主题照它重出，不要手修图 |

鸿蒙要位图的地方（比如分层图标的前景必须是 PNG），从 SVG 按需要的尺寸导出，**不要拿旧的 1024 PNG 再放大**。

## 数据模型 / 后端接口 / 备份包

都没有变化。

## 任务卡

**U17-1 换成矢量素材**（可选）
- 目标：桌面图标和设置里的图标预览在大屏、高分屏上边缘清楚
- 先读：U09「素材」、本包「规则」
- 要做：前景层和图标预览换成上表的 SVG（鸿蒙支持矢量的地方直接用；必须位图的按目标尺寸从 SVG 导出）
- 不要：改图形、构图、颜色；拿旧的 1024 PNG 放大
- 验收：和旧图标并排看，位置大小颜色一样；放大看边缘没有锯齿

## 鸿蒙已经做了的部分怎么改

照 U09 用 `m.png` 做好的不用拆，外观本来就一样；U17-1 做不做由鸿蒙排期定。
