先读这五条

1. 照字做，不用看图：每一页长什么样、东西在哪、弹在哪，都写在字里；颜色、字号见第三节的表，代码骨架也在第三节。

screenshots/ 是 iOS 模拟器上截的图，只给人对照，agent 不用打开、不能当规格（截图里二级页的小图标是苹果的 SF Symbols，不许用到鸿蒙上，见 ../icons/ICONS.md 第 2 条）。每一行用哪个鸿蒙图标，写在那一行的「鸿蒙 sys.symbol.」一列

2. 图标两种来源：设置首页行首是尺素自己画的线条 → 用 U10 给的图片（按文件名放进资源，$r('app.media.文件名')）；二级页及以下全部用鸿蒙系统的 HarmonyOS Symbol（SymbolGlyph($r('sys.symbol.xxx'))）。火漆印照 ../icons/ICONS.md「火漆印」一节的 ArkTS 代码画

3. 文案：这里写的是简体中文，也就是 iOS Localizable.xcstrings 的 key，七种语言的译文都在 iOS 快照的 xcstrings 里，按 key 取，不要自己翻

三、二级页的样子（所有二级页通用）

- 顶上：左上角圆形返回钮；正中一行小标题（主题的小号字、字距拉宽、次要文字色），不是大标题

- 页面底色 / 卡片底色：U10 的 R-SETTINGS-08（页面底比卡片深一档）。设置下面所有页面都用这一组，写作统计除外

- 分组卡片：圆角卡片一组一组排，组与组之间留空；组下面可以有一段灰色小字（footer），组上面可以有一行灰色小标题（header）

- 一行：

- 行首图标：HarmonyOS Symbol 14vp（和 iOS 同号），次要文字色；图标占 20vp 宽，和文字间距 10vp。不套框（套框的只有首页）

- 行名：主题的正文字、主文字色

- 右边：要么是当前值（主题的小号字、第三级文字色），要么是开关（打开时是主题强调色），要么是 >（sys.symbol.chevron_right，第三级文字色）

- 一行说明文字（比如「只记到城市，如「广州市」」）是卡片里单独的一行，小号字、第三级文字色，跟着上面那个选项变

- 点了是动作、不是进页面的行（导出备份、导入备份）右边也是 >；跳到别的 App 的（首页的评分、反馈、关注我们）右边是 ↗（sys.symbol.arrow_right_up_and_square）

代码骨架（ArkTS，名字以 DevEco 补全为准）

// 二级页的一行：行首图标 + 行名 + 右边（三选一）
@Builder
settingsRow(icon: Resource, title: ResourceStr, trailing: 'chevron' | 'toggle' | 'value', value?: string) {
  Row() {
    Row() {
      SymbolGlyph(icon)                         // 例：$r('sys.symbol.bell')
        .fontSize(14)                           // 14vp
        .fontColor([this.theme.textSecondary])
    }
    .width(20).justifyContent(FlexAlign.Center) // 图标占 20vp 宽，居中
    Text(title)
      .fontSize(14).fontFamily(this.theme.bodyFamily)
      .fontColor(this.theme.textPrimary)
      .margin({ left: 10 })                     // 图标和字之间 10vp
    Blank()
    if (trailing === 'value') {                 // 当前值：小号字、第三级文字色
      Text(value).fontSize(12).fontColor(this.theme.textTertiary)
    }
    if (trailing === 'chevron' || trailing === 'value') {
      SymbolGlyph($r('sys.symbol.chevron_right')).fontSize(14).fontColor([this.theme.textTertiary])
    }
    if (trailing === 'toggle') {
      Toggle({ type: ToggleType.Switch, isOn: this.isOn }).selectedColor(this.theme.accent)
    }
  }
  .width('100%')
}

// 行尾小菜单（手记页、位置精度）：值显示在行尾，点了在值的左下方弹出小菜单，当前项打勾
Select([{ value: '市' }, { value: '区县' }, { value: '街道' }])   // 字从 xcstrings 取，这里只示意
  .selected(this.precisionIndex)
  .value(this.precisionLabel)
  .font({ size: 12 }).fontColor(this.theme.textTertiary)
  .onSelect((index: number) => { this.savePrecision(index) })     // 选了立刻存、立刻生效

// 小气泡（提醒时间）：灰底圆角胶囊「21:00」，点了在胶囊下方弹出时、分两列滚轮
Text(this.timeLabel)
  .padding({ left: 12, right: 12, top: 6, bottom: 6 })
  .borderRadius(16)
  .backgroundColor('#1F767680')                 // 浅灰底（系统填充色那一档）
  .bindPopup(this.showTimePopup, {
    builder: this.timeWheel,                    // 里面一个 TimePicker，滚动即存
    placement: Placement.Bottom,
    onStateChange: (e) => { if (!e.isVisible) this.showTimePopup = false }  // 点外面收起
  })
下面每一页的表格里，「鸿蒙 sys.symbol.」一列就是要用的图标名，写成 SymbolGlyph($r('sys.symbol.名字'))；写「—」的那一行没有图标。
