## 一句话

**免费版本身就好用，开通会员后眼前一亮，让人觉得 ¥58 值得。**

## 四条原则

1. **写、存、读、同步、导出永远免费，不设上限。** 日记是用户自己的东西，锁数据就是拿日记当人质。
   私密日记的口碑全靠这一条；iCloud 用的是用户自己的空间，我们没有成本。
2. **免费版每一类都给「一个完整的好东西」，不给残缺版。** 主题能用到底，相纸有拿得出手的，笔友每周真的会来信。
3. **会员卖两样：「被回应」和「更多的美」。** 被回应 = 写一篇笔友回一篇，这是尺素最独特的地方，
   每封信有真实成本，也正好是 Apple 要求订阅提供的「持续价值」；更多的美 = 更多相纸、版式、信纸，以及持续上新。
4. **付费入口只在心动的时刻出现，绝不打断写作。** 收到一封信时、在相纸选择器里看到更美的那张时。
   先让用户用自己的照片看到效果，再问要不要。

2026-10-27 用户定：**界面上直接讲邮票数**（付费页「每周 20 张邮票 / 一张邮票寄一封信，每封都有回信；免费每周 3 张，没用完的一直攒着」、笔友地图右上角一张小邮票 + 余额数字），不再说「每周几封」。仍然不写「本月剩余 N 封」这类倒数。

## 价格

| 方案 | 价格 | 说明 |
|---|---|---|
| 年付 | **首年 ¥58**，之后每年 ¥88 | **付费页默认选中**；小字写「首年约每月 ¥4.8，之后每年 ¥88」（2026-10-17 改：「首年」打头，这个月价是按首年价折的；金额的货币符号跟着 App Store 店面走） |
| 月付 | ¥12 / 月 | 放在年付旁边当参照（一年 ¥144） |

- **不给免费试用**。Apple 规定同一订阅组里一个 Apple ID 只能享受一次新用户优惠，试用和首年 ¥58 只能二选一；
  免费版已经能体验笔友（每周 3 张邮票），不太需要试用
- **首年价只享受一次，第二年起 ¥88 续费 —— 付费页必须写清楚**（Apple 的硬性要求）
- **不开家人共享**：日记是很私人的东西，共用需求不大，每个人的笔友来信都有成本。
  ⚠️ 这个开关在 App Store Connect 里**一旦打开就关不掉**，以后要开先想清楚
- 订阅组名、对外名称：**尺素会员**（英文 Memoir Plus，其余语言另译）
- 原「皮革主题单独 ¥25」作废（皮革 2026-08-12 起免费），App Store Connect 里那条内购要下架（上架清单 B10）

## 会员到期之后

**已经用上的保持原样**：旧日记里的高级相纸、已经设好的白框 / 贴照片封面、已经收到的火漆信件、导出过的 PDF，一律不动；
只是不能再给新东西用。用户的日记不会因为停了会员而变样。

来信回到免费节奏；世界笔友不能再寄，剩下的邮票只能寄给自己那一位（这是「以后怎么写」，不是已有的内容）。

## 上架范围

**会员专属（信件升级、世界笔友、情绪小结、精装 PDF）全部做完再上架**（产品负责人定；2026-10-27「月度 / 年度回望」改成写作统计里的情绪小结，产品负责人定：尺素是效率工具，以后往健康和生活扩展，第二期把心情写进「健康」）。2026-10-23 删掉「笔友性格」：世界笔友本身就是 15 种性格；付费页那一条 2026-10-27 换成「今雨与雅故」（世界笔友在界面上的名字）。

## 测试期：假开通与来信放开（2026-10-10 起，上架前关）

产品要求在 App Store Connect 建好订阅之前，会员和来信都能先试用：

- **iOS `StoreKitManager.testUnlock = true`**：付费页照常显示（拿不到商品就用预设价格），点「开通尺素会员」不付款、直接在本机记成会员；
  设置 → 尺素会员里可以「关闭测试会员」回到免费版。假会员不交给服务器
- **服务端 `LETTER_RHYTHM_OFF=1`**（`china/s.yaml`）：来信节奏不设上限，写一篇就能收一封

两个都在上架清单 **A0c**，上架前必须关。

## 本地测试购买（不用等 App Store Connect）

仓库里有 `StoreKit/Memoir.storekit`（两个产品 + 年付首年 ¥58 优惠）。在 Xcode 里：
**Product → Scheme → Edit Scheme… → Run → Options → StoreKit Configuration** 选它，
之后从 Xcode 运行就能走完整的购买 / 恢复流程，不花钱、不需要沙盒账号。
⚠️ 本地配置签出来的交易**过不了服务器验签**（不是 Apple 签的），所以本地测试时服务器那步会失败，
笔友来信额度不会变 —— 这是预期的。真正的端到端要等 App Store Connect 建好产品后用沙盒账号测。
